# MyFigma 产品原型 v1.2

双击 `index.html` 即可打开，无需安装依赖或联网。建议桌面浏览器，1440×900 或更宽；完整编辑器最小宽度 1130px。也可以在本目录运行 `python -m http.server 8765 --bind 127.0.0.1`，打开 `http://127.0.0.1:8765/`。

## 页面

- `#home`：项目中心，项目搜索、项目卡片和新建项目入口；打开已有项目或新建项目都会直接进入编辑器。
- `#editor`：三栏编辑器，左侧 AI 助手/图层 tabs、对话式生成与运行记录、节点选择、右侧属性、撤销和缩放。
- `#orchestration`：1 个协调者 + 5 个执行者、并发设置、任务委派、工具输入输出、Loop 状态与取消恢复。
- `#validation`：截图证据对照、Round 0/1/2、七维检查、节点与执行者定位、Patch、复审及人工处理。
- `#history`：快照恢复与中断 Run 模拟续跑。
- `#mcp`：五个工具、客户端配置、模拟连接测试。
- `#code`：建议文件树、示例代码、静态设计预览、下载交付清单。
- `#assets`：Token 与内嵌 SVG 资产。

## 推荐评审路径

项目中心 → 新建项目或打开已有项目 → 在 AI 助手对话中描述需求并生成 → 切换图层 → 点击首屏 → 改标题与颜色 → 撤销 → 查看验证报告 → 定位 / 模拟修复 → MCP 接入 → 代码交付。

完整模拟默认约 18 秒。可选择“逐步演示”，逐次推进委派、合并、截图、自审、修复、Patch 和复审。初检 3 项问题，第 1 轮复审剩 1 项，第 2 轮复审通过；修复最多两轮。场景可切换为“耗尽留警告”或“耗尽留阻断”。剩余警告可填写理由人工接受；阻断与人工修改冲突不能直接接受。可取消后从检查点继续，也可在历史页从 3/5 区域模拟续跑。

优先评审：多 Agent 协作 → 加载协作阶段示例 → 查看画布光标 → 视觉自审 → 首轮审查示例 → 下一步 → 修复委派 / 应用 Patch / 新截图 / 复审。也可直接加载各阶段示例。所有生成、问题、截图元数据和工具返回均为固定模板模拟；不同需求不会真实生成不同页面。属性/版本变更仅在当前内存中，刷新会重置。

## 范围说明

这是产品评审原型，画布以 DOM 模拟，未实现生产 Canvas、自由拖拽、真实保存、真实 AI、MCP Sidecar、Figma 导入或 React 工程构建。MCP 配置使用占位值；下载 JSON 是原型状态与清单，不是正式可导入 DSL / 工程源码。品牌插画为本地内嵌 SVG，无远程素材与外部依赖。

静态原型图：`screens/`，共 14 张；P02 创建工作流截图仅保留为历史评审参考，应用不再提供该页面入口。P10–P14 是协作和闭环状态。可分享图册：`prototype-atlas.pdf`，共 15 页；全景概览：`prototype-overview.png`。正式设计方案见工作区 `.agents/Documents/需求分析/需求/2026-09-30-15-47-类Figma-AI项目详细设计.md`，重点阅读 4.12、4.13、6.5、10.3。
